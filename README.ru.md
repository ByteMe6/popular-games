# popular-games

Коллекция интерактивных мини-игр на ванильном JavaScript с Parcel.

**[Live Demo](https://ByteMe6.github.io/popular-games/)**  |  [English](./README.md)

## Игры

| Игра | Описание |
|------|----------|
| Високосный год | Проверь, родился ли ты в високосный год |
| Угадай число | Классическая игра с подсказками |
| Камень-ножницы-бумага | Игра против компьютера |
| Калькулятор | Простой арифметический калькулятор |
| Калькулятор времени | Вычисление временных интервалов |
| Дино | Бесконечный раннер |
| Футбол | Футбольная мини-игра |
| Три числа | Числовая головоломка |
| Слайдер | Компонент карусели изображений |
| Наука | Викторина |

## Технологии

- Vanilla JavaScript
- Bootstrap 5.3
- SASS
- Parcel 2 (сборщик)

## Запуск

```bash
npm install
npm start
```

Откроется на [http://localhost:1234](http://localhost:1234).

## Сборка

```bash
npm run build
```

Результат в папке `dist/`.
