# popular-games

A collection of interactive mini-games built with vanilla JavaScript and Parcel.

**[Live Demo](https://ByteMe6.github.io/popular-games/)**  |  [Русский](./README.ru.md)

## Games

| Game | Description |
|------|-------------|
| Leap Year | Check whether you were born in a leap year |
| Guess the Number | Classic number guessing game with hints |
| Rock Paper Scissors | Play against the computer |
| Calculator | Basic arithmetic calculator |
| Time Calculator | Calculate time intervals |
| Dino | Infinite runner game |
| Football | Football mini-game |
| Three Numbers | Three-number puzzle |
| Slider | Image slider component |
| Sci | Science quiz |

## Tech

- Vanilla JavaScript
- Bootstrap 5.3
- SASS
- Parcel 2 (bundler)

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:1234](http://localhost:1234).

## Build

```bash
npm run build
```

Output goes to `dist/`.
